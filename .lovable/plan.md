# sasuty — X(Twitter)風UI + アニメーション強化

現状のThreads寄りUIを、Xに近い操作感（青アクセント、アクションバー、フローティング投稿ボタン、スティッキータブ）に寄せつつ、読み込み中のスケルトンと各種マイクロアニメーションを追加する。バックエンド・データロジックは変更しない。

## X風UIへの寄せ方

- **カラー/トークン**: `src/styles.css` に X 由来のアクセント（青）と、いいね=ピンク赤・リポスト=グリーンのアクションカラーをセマンティックトークンとして追加。背景はほぼ黒、区切り線を細く。角丸はボタンは完全ピル、カードは角なし。
- **ヘッダー**: 中央にロゴ、左に自分のアバター、右にDM。スクロールで半透明ブラー＋わずかに縮む。
- **タブ**: 「おすすめ / フォロー中」をスティッキー化し、アクティブ下線を幅アニメーション付きに。
- **投稿カード**: X準拠のレイアウト（表示名 + @username + ・時刻 を1行、本文、画像は角丸ボーダー付き、アクションバーは 返信 / リポスト / いいね / 共有 を等間隔配置、ホバー時にアイコン背景の丸ハイライト）。カード全体クリックでスレッドへ。
- **フローティング投稿ボタン**: 右下に円形の作成ボタン（下タブの上）。下タブはアイコンのみで X 風の太さに。
- **プロフィール / 検索 / アクティビティ / DM一覧**: 同じカード・行スタイルに統一（フォローボタンはピル、ホバーで「フォロー中→フォロー解除」表示切替）。

## アニメーション

- **読み込み**: 各画面に専用スケルトン（フィード投稿、プロフィールヘッダー、通知行、DM一覧、チャットバブル）。既存の「読み込み中…」テキストを全て置換。シマー（左→右の光沢）ユーティリティを `styles.css` に追加。
- **リスト表示**: 投稿・通知・検索結果が index に応じた遅延で fade+slide-in。
- **いいね**: タップでハートがポップ（scale bounce）＋カウントの数字がスライド切替。
- **リポスト**: アイコンが回転して緑にフラッシュ。
- **画面遷移**: ルート切替時に軽い fade-in、モーダル（コンポーザ）は下からスライドアップ + 背景ブラー。
- **ボタン/タブ**: 押下時 active:scale-95、タブ下線のスライド、ボトムタブのアイコンがアクティブ時にポップ。
- **DM**: 新着メッセージのバブルが下からスライドイン、送信中は淡い半透明表示。
- **その他**: プルトゥリフレッシュ相当のトップスピナー、無限スクロール末尾のローダー、`prefers-reduced-motion` 尊重。

## 技術メモ

- アニメーションは Tailwind のキーフレーム/ユーティリティを `src/styles.css` に定義して使用（追加ライブラリなし）。色は全てセマンティックトークン経由。
- 共通スケルトンは `src/components/skeletons/` に集約、既存 `ui/skeleton.tsx` を利用。
- 変更対象は主に `styles.css`, `AppShell.tsx`, `PostCard.tsx`, `Composer.tsx`, `ProfileView.tsx`, 各ルートの表示部分のみ。API・RLS・認証には手を入れない。
